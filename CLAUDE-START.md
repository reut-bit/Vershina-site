# Передача сайта «ВЕРШИНА РЕЗУЛЬТАТА» для дальнейшей работы

## Как открыть и продолжить

1. Распакуйте архив целиком. Откройте `site/index.html` в браузере.
2. Файлы внутри `site/` — актуальная версия сайта. Сохраняйте структуру папок: страницы используют относительные ссылки на фотографии и документы.
3. Передайте Claude этот документ, `site/index.html` и `site/diplomy-i-razvitie.html`. Если интерфейс принимает ZIP, приложите весь архив. Если ZIP не принимается, передавайте нужные файлы из распакованного архива по отдельности. Само прикрепление архива не гарантирует, что сервис прочитает всё его содержимое.
4. Для дальнейших изменений используйте текст задания в конце этого документа. Просите вернуть изменённые файлы и полный комплект сайта с сохранёнными вложениями.

## Устройство сайта

Это статический сайт на русском языке без сборки и установки зависимостей. HTML, CSS и небольшой JavaScript находятся в двух страницах.

- `site/index.html` — главная: услуги, подход, оборудование, команда, цены, вопросы и контакты.
- `site/diplomy-i-razvitie.html` — документы команды и хронология обучения.
- `site/team/` — фотографии специалистов.
- `site/diplomas/` — 22 уникальных оригинала документов и миниатюры, по одному на карточку галереи. Два побайтно одинаковых дубля (document-03, document-08) и каталог `diplomas-catalog.json` перенесены в `source-materials/`.
- `pered-publikatsiey.md` — рабочие замечания перед запуском (вне папки `site`, не публикуется).
- `source-materials/` — исходный черновик, четыре прайса, исходники портретов и образцы оформления.
- `FILE-MANIFEST.json` — перечень файлов с размерами и SHA-256 для проверки целостности.

Сайт не опубликован в интернете. Формы отправки заявок и серверной части нет. Запись — через ссылки на телефон и Telegram. Данные посетителей сам сайт не сохраняет. Галерея открывает оригиналы документов и предлагает скачивание.

## Стиль и принципы

Современный, спокойный, не перегруженный сайт для родителей. Основные цвета: тёмный бирюзово-зелёный `#104d4c`, светлый зелёный `#c5ef83`, светлый фон `#f3f7f5`. Сохранять существующий логотип и адаптивную вёрстку.

Услуги и цены оформлены раскрывающимися блоками. Фотографии сотрудников — без текста, на светлом фоне с растениями и бирюзово-зелёными акцентами, со скруглённой рамкой. Для будущих фото важно максимально сохранять реальные черты лица, возраст и естественную текстуру кожи.

Не добавлять вымышленные отзывы, образование, статистику, гарантии результата и лечебные обещания. Текст в исходных рекламных изображениях не следует автоматически переносить на сайт как проверенный факт. Дипломы, сертификаты, справка о зачислении и лицензии — разные виды документов: не подменять один другим.
