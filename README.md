# Вершина результата — сайт центра

Статический сайт без сборки: HTML, CSS и немного JavaScript.

- `site/` — то, что публикуется: `index.html` (главная), `diplomy-i-razvitie.html`, фото команды и документы.
- `source-materials/` — исходники (прайсы, портреты, черновик). На сайт не попадают.
- `CLAUDE-START.md` — описание сайта и правила для дальнейших правок.
- `pered-publikatsiey.md` — рабочие замечания перед запуском.

## Хостинг и деплой

Сайт размещён на виртуальном хостинге Timeweb (тариф Optimo), основной сайт аккаунта `cj110251`:
https://cj110251.tw1.ru — временный технический домен.

Файлы лежат в `~/public_html` на сервере `vh460.timeweb.ru`. Обновление — из корня репозитория:

```bash
./deploy.sh --dry-run   # показать, что изменится
./deploy.sh             # загрузить
```

Скрипт синхронизирует `site/` с `public_html` через rsync по SSH-ключу: новые файлы загружаются, удалённые из `site/` удаляются на сервере, `cgi-bin` не трогается.

Картинки и PDF сервер отдаёт с кэшем на год. Заменённое фото кладите под новым именем, иначе посетители долго будут видеть старое.

Render не используем: он отдаёт сайты через Cloudflare, а Cloudflare в России ограничивают провайдеры.

## Локальный просмотр

```bash
python3 -m http.server 8765 --directory site
```
